# ✊✋✌️ Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

---

## 📖 Description

This project is a browser-based implementation of the classic Rock Paper Scissors game. The user plays against the computer by selecting Rock, Paper, or Scissors. The computer randomly generates its choice, and the game determines the winner based on standard rules.

The game keeps track of both the user's score and the computer's score, and displays the result after each round.

---

## ✨ Features

- 🎮 User vs Computer gameplay
- 🤖 Random computer choice generation
- 🏆 Automatic winner detection
- 📊 Live score tracking
- 🎨 Interactive and responsive user interface
- 💬 Dynamic result messages

---

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/zishan4hmed/Rock-Paper-Scissors-Game.git
   ```

2. Open the project folder.

3. Open `index.html` in any web browser.

4. Choose Rock, Paper, or Scissors to start playing.

---

## 🎮 How to Play

- ✊ Rock beats Scissors
- ✋ Paper beats Rock
- ✌️ Scissors beats Paper

### Rules

1. Click on one of the three choices.
2. The computer randomly selects its choice.
3. The winner is determined automatically.
4. Scores are updated after every round.
5. Continue playing as many rounds as you like.
